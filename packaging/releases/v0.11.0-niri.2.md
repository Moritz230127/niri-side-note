# Niri 侧笺 v0.11.0-niri.2

修复一个影响基本使用的回归：**收起态贴边条没有透明缓冲区**。

## 问题

`0.11.0-niri.1` 把贴边条改成 45px 宽的边带后，收起态只创建了 layer surface，但没有附加任何缓冲区（协议里只有 `commit`、没有 `attach`）。合成器不会把这种表面视为可交互表面，于是：

- 鼠标移到屏幕边缘不会展开标签；
- 看起来像“应用没启动”或“贴边没反应”。

## 修复

- 在贴边条根节点加入透明 `DrawingArea`，收起态也会绘制透明缓冲区并提交。
- 输入区域保持为整条选定边的热区（实测 `wl_region.add(18, 0, 27, 1067)`，即 45px 带子外侧的 27px × 全高触发区）。

## 其余

功能与 `v0.11.0-niri.1` 相同：整条选定边框触发、手动选屏、圆角标签、简体中文、按需映射的便签面板与键盘焦点修复。

## 安装

```bash
sudo pacman -Syu
```

包版本 `niri-side-note-bin 0.11.0-2`。已安装用户升级后：

```bash
systemctl --user restart niri-side-note.service   # 若使用 systemd 用户服务
```

或重新登录。
