# Niri 侧笺 v0.11.0-niri.1

这是一个以稳定性与可用性为主的重构版本。应用仍是贴边便签：标签常驻屏幕边缘，鼠标靠近展开，点开后在贴边面板里编辑。

## 主要变化

### 触发与选屏

- **整条选定边框都是触发区**：贴边带沿所选屏幕的选定边拉伸到全长，鼠标落在带内任意位置都会展开，不再依赖“瞄准某个点/线”。
- **手动选择屏幕**：设置里按 connector（例如 `eDP-1`、`HDMI-A-1`）选择贴边所在屏幕，也可以保留“自动”。切换后立即生效并写入配置。
- 自动模式会保留当前屏幕，显示器列表顺序变化时不再跳屏。
- 上 / 下 / 左 / 右四条边都按同一套几何规则放置。

### 标签外观

- 标签改为**简洁圆角**样式：11px 圆角、便签自身颜色填充、细边与轻阴影。
- 当前打开的便签用白色描边区分，其余标签降低透明度；完整标题保留 tooltip。
- `新建 / 搜索 / 全部便签` 合并为一个圆角工具胶囊，不再有细碎边框、渐变和内阴影。

### 仅中文

- 颜色名称、托盘菜单、字体/平台错误提示、包描述等残留英文全部改为简体中文。
- 界面、菜单、空状态、日期、CLI 描述与错误提示均为简体中文。

## 稳定性修复

- **启动后贴边条没有反应**：修复 layer surface 停在 200×200、没有输入区域的问题；现在启动即为整条边带，第一帧即可展开。
- **打开便签后打不了字 / Esc 关不掉**：贴边面板改为按需映射并以 OnDemand 获取键盘焦点，打开后可直接输入，Esc 可关闭。
- **关不掉 / 退不出**：便签格式数据损坏时按纯文本恢复，不再永久阻止保存与关闭；保存失败对话框提供“放弃修改并退出”。
- **再次启动没反应**：在已运行时再次启动会展开贴边条（或呈现“全部便签”），不再静默退出；带动作的启动（如 `--toggle-strip`）不会被额外的展开打断。
- 面板只在需要时映射，空闲时不再保留整屏透明 layer surface。

## 兼容性

- 需要 Wayland 合成器与 `zwlr_layer_shell_v1` v4+；已在 niri 26.04 验证。
- 依赖：GTK 4、libadwaita、`gtk4-layer-shell >= 1.0`（Arch 包会一并安装）。
- 配置与数据目录保持不变：`~/.config/stickies/config.toml`、`~/.local/share/stickies/notes.db`。
- 应用 ID 暂未改动，与旧版本数据兼容。

## 安装（Arch，rodriguez 仓库）

```bash
sudo pacman -Syu
sudo pacman -S niri-side-note-bin
```

安装后的命令是 `niri-side-note`，桌面文件为“Niri 侧笺”。

## 验证记录

- `cargo fmt --all -- --check`、`cargo clippy --locked --all-targets -- -D warnings -A deprecated`、`cargo test --locked` 通过（54 passed；23 个需要显示环境的测试仍 ignored）。
- 在 niri 26.04 + GTK 4.24 + gtk4-layer-shell 1.3.0、双屏（eDP-1 1706×1066@1.5、HDMI-A-1 2560×1440@1.0）上实测：
  - 四条边与两块屏幕的组合都能落在正确屏幕/正确边，尺寸与 margin 正确；
  - 打开便签后使用虚拟键盘输入可正常落库，Esc 可关闭；
  - 再次启动有可见反馈。
- 贴边带厚度固定为 45 逻辑像素（略大于标签深度），这是“整条边触发”与标签可见性的折中；后续可做成设置项。
